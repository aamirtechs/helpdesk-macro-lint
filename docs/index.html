Free open source tool

helpdesk-macro-lint

Check an exported Zendesk macro library in one local pass and find the broken placeholders, dead links and duplicate macros before your agents do.

View source on GitHub

What it does

  • Placeholder syntax and dictionary checks for ticket, requester, assignee, organization, group and current user fields, plus numeric custom field placeholders
  • Unknown placeholders and malformed or unbalanced placeholders reported as errors
  • Links starting with http:// flagged, since macro links should use https
  • References to fields from a deleted-fields list flagged, so renamed or removed fields stop breaking replies quietly
  • Duplicate and near-duplicate titles flagged by normalised comparison, and inactive macros listed

Install and usage

Requires Node.js 20 or later. There are no dependencies to install.

git clone https://github.com/aamirtechs/helpdesk-macro-lint.git
cd helpdesk-macro-lint
node src/cli.js examples/macros.json --deleted-fields examples/deleted-fields.txt --out-dir out

Input is a Zendesk macros JSON export, either a top-level array or an object with a macros array. The run writes report.md and findings.csv. Exit code is 1 when errors exist.
